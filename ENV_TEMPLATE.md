# Environment Variables Template for Sanity CMS Blog

# Sanity CMS Configuration

NEXT_PUBLIC_SANITY_PROJECT_ID=your-project-id-here
NEXT_PUBLIC_SANITY_DATASET=production
NEXT_PUBLIC_SANITY_API_VERSION=2024-01-01

# Sanity API Token (get from https://sanity.io/manage)

# Token needs read permissions for production dataset

SANITY_API_TOKEN=your-sanity-read-token-here

# Site Configuration

NEXT_PUBLIC_SITE_URL=https://your-domain.com

## How to get your Sanity credentials:

## 1. Go to https://sanity.io/manage

## 2. Select your project

## 3. Project ID is shown in project settings

## 4. Create API token in "API" section with "Read" permissions
